# 枫趣冒险（联机冒险棋）规则文档

> 本文档是「枫趣冒险」的**单一事实源**：PHP `App\Service\Adventure\*` 与前端 `pages-adventure/utils/adventure.ts` 的实现、`test/algo.test.ts` 的测试用例，都以本文为准。改规则先改这里。
>
> 对外名：**枫趣冒险**（与「枫趣牌局」成对）；tool_key=`adventure`；route=`/pages-adventure/index`。

## 1. 概述

- **人数**：2-6 人联机，微信好友房间制（4 位数字房间码）。
- **路线长度（房主设定）**：开局前房主在等待室选登顶格——**枫林 40 / 溪谷 60 / 岩壁 80 / 枫顶 100**（都在段边界上，默认 100）。短局时登顶格之后的区域**云雾封锁不可达**，枫顶旗画在登顶格上；雪线专属内容（决斗翻倍、封顶暴雪）只出现在 100 格完整局。
- **时长目标**：4 人约 12-15 分钟（100 格），60 格约 8-10 分钟。
- **胜利**：率先**精确到达登顶格**者夺冠；整局打满全部名次。
- **核心循环**：掷双骰 → （可选）打道具 → 走子 → 触发机关链 → （可能）决斗 → 播报。
- **设计支柱**：每回合恰好一个决策点（知情决策）；落后有追赶手段；互动（决斗/干扰/换位）但不淘汰人；全场共同事件（天气/雪崩）制造"一起抬头"时刻。

## 2. 棋盘总览

- **100 格，10×10 蛇形盘**：1 在底行左端，奇数行从左到右、偶数行从右到左，向上盘旋，100（枫顶）在顶行。
- **五段各 20 格**（= 每段两行，视觉上五条横带）：

| 段 | 格区间 | 主题 | 决斗形式 | 特点 |
|---|---|---|---|---|
| 山脚草原 | 1-20 | 教学段 | 猜拳 | 机关温和 |
| 枫叶林 | 21-40 | 枫叶富集 | 暗标枫叶 | 枫叶格多、埋伏/商店/山神 |
| 清溪谷 | 41-60 | 休整段 | 比点数 | 温泉/补给/命运交换 |
| 岩壁 | 61-80 | 险峻段 | 猜拳 | 滑坡落石密、缆车捷径、擂台 |
| 雪线 | 81-100 | 冲顶级 | 猜拳（筹码翻倍） | 机关最密、终局对决 |

- **营地**（存档点+绝对安全区）：**21 / 41 / 61 / 81**。安全 = 不可被顶退、不可被决斗、不可埋伏；任何回退不跌破自己**已到达的最近营地**（开局起点视为虚拟营地 0）。

- **岔路口**：30（缆车直达 44 vs 山道）、66（捷径直达 78 vs 安全绕行）。
- **大连锁**（故意设计）：云梯 58 → 缆车 62 → 79。

## 4. 回合流程与状态机

```
[房主 start] → phase=opening（🎯 定先手：全员各掷一次双骰，10s 超时代掷）
   ↓ 双骰之和最大者先手；最大点并列只由并列者重掷（上限 3 轮后随机定）
[advanceTurn] → phase=act（轮到 currentSeat 掷骰，20s）
   ↓ POST /roll（服务端掷 2d6）
phase=resolve（10s 决策窗口：可打任意数量道具，POST /move 确认走子；超时=不打道具直接走）
   ↓ POST /move → 位移结算
落格结算（顺序进行，遇到选择窗暂停等待）：
[若落点是岔路]   → pendingChoice{kind:fork}   （8s，超时=山道）
[若落点是埋伏格] → pendingChoice{kind:ambush} （8s，超时=不埋；枫叶<2 或格上已有雷则跳过）
[机关链位移]（云梯→缆车→滑坡→…依次，见 §6）
[若落点是商店]   → pendingChoice{kind:shop}   （8s，超时=不买；手牌满则跳过）
[若落点是山神]   → 山神猜拳（服务端即出）→ 赢则 pendingChoice{kind:shrine}（8s，超时=随机奖励）
[若落点是擂台]   → pendingChoice{kind:arena}  （8s，超时=前方最近玩家）
[若落点有其他玩家] → 狭路相逢决斗 pendingDuel（10s，超时=随机代出）
[决斗结算+押注赔付]（胜者 +1 若再踩人 → 普通顶退 2，不再决斗）
   ↓
[advanceTurn：消费 skipNext → 最后一人的回合结束 → 翻天气牌]
```

- **超时链**：全部由清扫器（1s tick）+ 写操作懒检查双轨推进；懒检查必须带请求者 userId 放行（防活跃玩家被 422 软锁，同 ludo 教训）。
- **挂机**：连续 3 次超时（idleStrikes）→ 自动托管（auto=true），真人任意操作解除。
- **托管行为**：自动掷骰、不打道具、不买不埋、岔路走山道、山神随机奖励、擂台选前方最近、决斗随机出拳/暗标 0-min(3,枫叶)。

## 5. 位移统一语义（所有位移共用一张规则表）

| 位移来源 | 登顶 | 超出 | 营地托底 | 触发落格机关 | 踩响埋伏 | 决斗 |
|---|---|---|---|---|---|---|
| 掷骰移动（含登山镐/雪球修正） | exact=登顶 | 可补票（§5.2），否则反弹 | ✅ | ✅ 全部 | ✅ | ✅ |
| 机关位移（云梯/缆车/滑坡/落石/岔路捷径） | exact=登顶 | 反弹 | ✅ | ✅（链） | ✅ | ✅ |
| 道具位移（大风咒/换位/缆车票/山神+4/决斗±/擂台±/顶退） | exact=登顶 | 反弹 | ✅ | ✅ | ✅ | ✅（决斗胜 +1 落点有人→只顶退） |
| 天气位移（顺风/山风/泥石流/龙卷风） | **可吹上 100=登顶** | 反弹 | ✅ | ❌ 不触发主动机关 | ✅ **会踩响埋伏** | ❌ |

- **反弹公式**：目标 = `100 - (pos + move - 100)` = `200 - pos - move`。
- **封顶暴雪**（规则牌生效期间）：目标 >81 的位移一律截断为 81 营地（起点已在 82-100 者在雪线内自由移动）。

### 5.1 掷骰移动
- 双骰之和（2-12）。**同点 = 捡 2 枫叶**（不额外行动）。
- 雪球减速：有效步数 = `max(1, 骰和 - 累计减速)`，减速消费后清除。
- 登山镐：骰和 +2。

### 5.2 补票登顶
掷骰移动若 `pos + move ≥ goal` 且 `move ≥ goal - pos`：
- 恰好 = goal：免费登顶。
- 超出且枫叶 ≥ 差额（`goal - pos`）：**自动补票**，扣差额枫叶，登顶。
- 超出且枫叶不足：反弹。
（补票只在掷骰移动时生效——机关/天气/道具把你送上去是运气，不收钱。）

## 6. 机关格详解

### 6.1 枫叶格 / 温泉
踩上即得枫叶：枫叶格 +2（花粉季 +4）、温泉 +2（烈日 +4）。

### 6.2 云梯 / 缆车
落格立即跳到目标格；缆车在「缆车停运」生效时视为普通格。落点继续触发落格机关（链）。

### 6.3 滑坡 / 落石
落格立即后退到目标格（暴风生效时后退距离翻倍——固定目标格按 2 倍距离换算，落点仍受普通格校验约束，实现时直接定义 `slide2` 目标）。落点不再触发机关（棋盘已保证落点是普通格/营地）。

### 6.4 商店
落格弹选择（8s，超时=不买）：花 3 枫叶买 1 随机道具（手牌满 3 不可买）。

### 6.5 补给站
免费摸 1 随机道具（烈日摸 2）。手牌满 3 时溢出转化为 +3 枫叶。

### 6.6 决斗擂台
落格弹选择（8s，超时=挑战**前方最近**玩家；自己第一则不触发）：挑战**任意**一名玩家决斗，筹码 **胜 +3 / 败 -3**（不受段位翻倍影响）。

### 6.7 埋伏格
- 踩到且枫叶 ≥2：弹选择（8s，超时=不埋）花 2 枫叶埋雷，雷落在该格，**归属对他人隐藏**（serialize 只给 `trapCount`）。
- 任何**对手**（非埋雷人）踩中（掷骰/机关/道具/天气位移均算）：触发 → 该对手 **-3 且跳过下一回合**，事件公示「这是 XX 埋的！」，雷消失。
- 每格同时最多 1 颗雷；营地/枫顶不可埋。

### 6.8 命运交换
落格立即与**前方最近**的玩家换位；自己是第一名 → +3 枫叶。换位双方位置对调，不触发任何落格效果。

### 6.9 山神小屋
落格与山神（服务端随机）猜拳，免费、立即出：
- **赢**：三选一（8s，超时=随机）：+4 前进 / 摸 1 道具 / +3 枫叶。
- **输**：交 2 枫叶买路钱；枫叶 <2 则退 2 格（营地托底）。
- 平局重猜至分出胜负（服务端循环，一次性结算，无窗口）。

### 6.10 雪崩格
落格触发：**你身后 5 格内**（`pos-5 ≤ 对方pos < pos`）的所有**其他**玩家退 2（营地托底，不触发机关）。触发者本人不动。

### 6.11 岔路口
落格弹选择（8s，超时=山道）：
- 30：A「缆车直达 44」/ B「山道」（原地不动，继续按正常路径走）。
- 66：A「捷径直达 78」/ B「安全绕行」（原地不动）。
捷径位移按机关位移语义（落点 44/78 均为普通格）。

### 6.12 营地 / 枫顶
- 营地（21/41/61/81）：安全区（见 §2）；路过不等于到达——**落在**营地格才算存档。
- 枫顶 100：登顶，进入 finishedOrder。

### 6.13 同格碰撞（顶退）
落点已有其他玩家且本回合已决斗过（或决斗豁免）→ 先到者被**顶退 2**（营地免疫；被顶者按道具位移语义落格）。同格可共存多枚棋子（前端微错位显示）。

## 7. 决斗系统（狭路相逢）

### 7.1 触发与形式
掷骰/机关/道具位移落点有其他玩家（非营地）→ 行动方**任选一名**同格玩家决斗（选择窗并入决斗窗：10s 内先选人再出招，超时=随机选人+随机出招）。形式由**落点段位**决定：

| 段 | 形式 | 玩法 |
|---|---|---|
| 草原 / 岩壁 / 雪线 | 猜拳 rps | 双方 10s 内暗出（互不可见），平局重出 |
| 枫叶林 | 暗标 bid | 双方 10s 内暗押 0-min(5,自己的枫叶)，价高者胜且**赢家支付所标枫叶**，平局转比点数 |
| 清溪谷 | 比点数 dice | 服务端各掷 1 骰即出，平局重掷（零等待） |

- 平局兜底：最多 3 轮，仍未分出 → 比点数强制分胜负。
- 超时：该方由服务端**随机代出**（猜拳随机、暗标随机 0-3）。

### 7.2 筹码
- 基础：**胜 +1 / 败 -3**（位移按道具语义，营地托底）。
- 雪线（81-100 落点）：**胜 +2 / 败 -6**。
- 猎风生效：胜者额外 +1。
- 擂台发起的决斗：**胜 +3 / 败 -3**（覆盖段位筹码）。
- 一回合最多 1 场决斗；胜者 +1 落点再有人 → 只按顶退 2。

### 7.3 押注（旁观参与）
决斗窗口期间（比点数形式除外），**非参战**在座玩家可花 1 枫叶押某一方（每人每场 1 注）。结算：押中**返还 3**（净 +2）。事件播报赔付结果。

## 9. 天气系统

- **牌库**：12 种各 1 张洗成数组存 `weather.deck`；`weather.current` 生效中、`weather.next` 预报（对全员公开）。deck 空时重洗 12 张。
- **翻牌时机**：一轮（所有在座玩家各行动一次）最后一个回合结束后：`current=next`、`next=deck.shift()`；即时牌立即结算，规则牌作用于新的一轮。第一轮 `current=null`（无天气），`next` 开局即公开。
- **改天换地**：弃 `next`，`next=deck.shift()`（deck 空重洗）。

## 10. 排名与终局

三组制（同 ludo）：
1. **登顶顺序** finishedOrder；
2. **活跃未登顶**：位置 desc → 座位号 asc；
3. **离开者**：`leftProgress`（离开时位置快照）desc → 座位号 asc——**中途退出永不排在存活者之后**。

- 胜因：`finish`（首个登顶后继续打完全部名次）/ `forfeit`（活跃 ≤2 时有人离开）/ `last_man`。
- 全员登顶或仅剩 1 名活跃玩家 → 终局结算。

## 11. 房间生命周期

```
waiting ──start──▶ playing ──房主 save──▶ saved ──resume──▶ playing
  │                  │                        │
  └──空房 closed ◀───┴──终局 finished ◀──────┤ 7 天过期 → closed
```

- **status**：`waiting / playing / saved / finished / closed`（+ `paused_at` 列）。
- **保存**：房主在 playing 时 `POST /save` → 清 deadline、status=saved、事件横幅；已暗出的决斗拳原样保留在 state。
- **续局**：房主 `POST /resume`（saved 超 3 天任何在座成员可续）→ status=playing、**所有窗口 deadline 重置为满额**、全员广播；未归/掉线座位由托管代打，随时重连接管。
- **全员离线守卫**：清扫器推进到期回合前查在线（WS 连接 ∪ seen_at 60s），**零人在线 → 自动转 saved**——绝不让托管通宵自己下完。
- **断线重连**：掉线 ≠ 离开。座位保留、离线角标（60s 无心跳）、轮到时托管代打；重连 = 同 token 重新 WS 握手（新 fd 替换旧 fd 并立即推全量首帧）或重新拉 `GET /room/{code}`；`GET /my-rooms` 提供「我的对局」入口（waiting/playing/saved）。
- **离开**：playing 中离开 → leftSeats + leftProgress 快照（排名规则见 §10）；saved 房离开照旧。rematch 只在 finished，剔除 leftSeats、保留 scores。

## 12. 聊天与贴纸

照抄枫趣牌局（uno）聊天子系统 + 第四种 kind：

| kind | 内容 | 校验 |
|---|---|---|
| phrase | 快捷语 id | PHP `AdventureChat::PHRASES` 白名单（TS `adventureChat.ts` 镜像同步 id） |
| emoji | 表情字符 | 白名单 |
| sticker | 贴纸 id | 白名单 id → CDN PNG（固定美术，**免 secCheck**） |
| text | 自由文字 ≤40 字 | `feature.adventure_chat_text`（默认 1）+ 全量 `msg_sec_check` **fail-closed**、事务外执行 |

- `state.chat` 环形 50 条 + `chatSeq` 单调 + `chatLastAt` 3s 冷却；开局/重开 `carryChat` 带三件套。
- 快捷语分组：通用 / 决斗挑衅 / 求饶 / 庆祝（决斗窗口时挑衅组前置）。
