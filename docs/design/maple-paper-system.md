## v4 设计令牌

- 底色 `#F6F9FB`（近白冷调）；卡片纯白 + 发丝线 `#EAF0F4` 描边（无阴影或极淡）
- 墨色三档（蓝灰）：`#2E4154 / #6E8093 / #A4B3C0`
- **唯一主色清新蓝**：`#58A6DC`（深 `#3B86B8`，浅底 `#E9F4FB`）——按钮、选中态、链接、图标点缀
- 功能色（柔）：成功 `#5FB98C` / 警示 `#E8806F`。**黄色/杏色不做任何实底填充**（蓝+黄不协调，用户 2026-09-22 拍板）：抽奖礼盒、开奖/完成按钮、成就标签等全部用主蓝或中性灰；黄色只允许作为极小面积的内容点缀（如飘叶），默认不用
- 工具/游戏个性 = **马卡龙淡彩图标底**（16 组 tint/fg，见原型 JS `PASTEL` 表），只用于图标小方块与标签，不撑满页面
- **全局禁渐变**；字重降档 300/400/500/600；图标线性 1.8 描边

## v4.1 对局 HUD 规范（游戏对局界面统一框架）

**功能真实性原则（2026-09-22 用户拍板）**：原型/设计稿只体现线上已存在的功能，不虚构「成就/排行榜/快速匹配/在线人数」等尚未实现的能力；确需新功能先立项再入稿。

**速度模式开关 + 单机大厅对齐现状（2026-09-22）**：俄罗斯方块大厅 = 开始游戏/排行榜 + 下落速度（越消越快⇄恒定速度）+ 初始等级 1~15 步进器 + 本地最高分 + 操作方式/音效（无成就、无章节进度——俄方块是无尽模式）；推箱子大厅 = **保持现有选关结构**（章节卡 + 关卡格 + 星级 + 锁定章），无成就/排行榜（收星总榜默认关），只换 v4 配色。

**新功能 · 俄罗斯方块速度模式开关（2026-09-22）**：新增「下落速度」开关——`越消越快`（现有 Guideline 等级加速公式，默认）/ `恒定速度`（全程基础速度，不随消行加速）。实现要点：`utils/tetris.ts` state 加 `speedMode`，tick 的重力间隔按模式二选一（恒定 = 恒取基础档）；对局内可即时切换，选择持久化到本地；计分/榜单统一不拆分。原型见 `#play-tetris` 顶部开关行。



统一结构：导航栏（返回 + 游戏名 + 房间码）→ 信息区（比分/玩家条/关卡）→ 棋盘区（内容色）→ 底部控制条（白底发丝线）。**防误触两原则：不可逆操作不与高频操作相邻；破坏性操作移到顶部并二次确认。**

- **俄罗斯方块**：控制排最终顺序 `← / → / 旋转(accent) / ⤓直落(蓝色实底) ‖隔离带‖ HOLD`——直落居内侧好按（高频），HOLD 低频靠边缘；防误触靠**蓝色实底视觉区分**（高频键全白）+ 快滑手势双通道。
- **推箱子**：「撤销(蓝色胶囊)/重开(图标+二次确认)」移到顶栏右侧；底部只留 64×58 大方向键（间距 10px，长按连走），周边无任何其它按钮。
- **配色审计（10 款）**：chrome（信息条/按钮/弹窗/聊天坞）全部转 v4 蓝白；棋盘牌面 = 内容色，处理如下——俄/推奶油金面板→白+淡彩棋子（金只留箱子/星标等内容）；uno/ludo/adventure 墨绿牌桌→白底，四季色/座位色转马卡龙；gomoku 木纹棋盘减淡为 `#FBF5E8`；jungle/junqi/xiangqi/tictactoe 浅木棋盘同 gomoku 处理，阵营红蓝转 v4 柔红 `#E8806F`/柔蓝 `#4A86B8`。
- **枫趣牌局（uno）**：布局沿用现状（对手条+牌堆+手牌+动作），仅调色——摸牌堆牌背墨黑→浅蓝底蓝枫叶；万能+4→中性灰；「当前颜色」指示器**跟随实际颜色**（红显示红 tint）；四季手牌维持马卡龙淡彩。控制排 HOLD/直落互换：高频直落居内侧（蓝色实底防误触），低频 HOLD 靠边缘。
- **常驻聊天坞（联机 8 款标配）**：对局底部固定白色圆顶坞（发丝线 + 毛玻璃）= 最近消息 feed（谁：说什么，蓝名 + 灰气泡）+ 底行 [💬 触发(蓝tint)] [说点什么…输入] [发送]；💬 点开底部面板（快捷/表情/文字 三 tab，自由文字经内容审核）；对局内容区预留坞高 padding。单机（俄/推）无聊天。

## 0. 定位与原则

**枫叶小屋 = 一间秋日午后的手作小屋**：纸质感的暖白、枫糖的甜、墨水的棕、一点墨绿的沉稳。

1. **只做浅色主题**（小程序场景 + 暖色品牌，不做深色模式）。
2. **chrome 严格归一，content 允许个性**：界面框架（底色/卡片/按钮/弹窗/导航/字阶）只从本规范取值；内容色板（拼豆色卡、纪念卡 8 场景、灵签牌库、方块/棋子色、ludo 座位色）保留个性但须在专用 theme 文件登记。
3. 特批保留的场景主题：灵签宋体 + 深红书卷（`$font-serif` 场景字体仅灵签可用）；anniversary 8 场景渐变。
